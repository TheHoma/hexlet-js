Мой первый проект на Хекслете

## Установка

Для установки зависимостей выполните:

```bash
make install
```

## Проверка кода

Проект использует oxlint и oxfmt.

Проверить код:

```bash
make lint
```

```bash
make lint-fix
```

- `make lint` — проверка кода линтером и форматтером
- `make lint-fix` — автоисправление ошибок и форматирование
